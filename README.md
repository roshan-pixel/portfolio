# Himanshi Parihar — UI/UX & Graphic Designer Portfolio (Interactive Clone)

This is an offline-ready, responsive, pixel-faithful interactive portfolio website for Himanshi Parihar, based on the Behance design portfolio layout ([Gallery #192698055](https://www.behance.net/gallery/192698055/UI-UX-and-Graphic-Designer-Portfolio)).

## 🌟 Features

- **Personalized Rebranding**: All references updated to **Himanshi Parihar** with contact email `himanshiparihar.design@gmail.com`.
- **Dynamic Work Filtering**: Category filter tabs (`All Work`, `01 Logofolio`, `02 Branding Systems`, `03 UI/UX Design`) with fluid section toggling and smooth scrolling.
- **Interactive TAP App Flow Explorer**: Toggle between contextual mockup and complete 9-screen clinical workflow.
- **Interactive Bloomcare AI Botanical Scanner**: Live camera diagnosis simulator identifying *Monstera Deliciosa* with custom treatment plans and real-time state feedback.
- **Iconic Brutalist / Pill UI Header**: Reproduces the pill browser search bar, bold `portfolio.` title, and 1-click clipboard copy triggers.
- **Interactive About & Resume Drawer**: Slide-out panel with quick navigation links, complete career timeline (NCL Holdings, AIC Hotel Group, ACL, Akane Digital, MultiCuba), education at the Higher Institute of Design (ISDi), skills, and software toolset.
- **Mobile Touch Gestures**: Full mobile touch swipe support (swipe left/right to navigate slides, swipe down to dismiss) on lightbox modals.
- **Mobile-Responsive Architecture**: Optimized for screens from 360px up to 4K displays with responsive grids, collapse-resistant typography, and touch-friendly targets.
- **100% Offline**: All 60 slide assets are cached locally in `assets/` (no external CDNs or Behance dependencies).

## 🚀 How to Run

### Method 1: Local HTTP Server (Active on Port 8080)
The local server is running in the background. Visit:
```
http://localhost:8080
```

To start or restart the server manually:
```powershell
cd C:\Users\sgarm\stephanie-perez-portfolio
python -m http.server 8080
```

### Method 2: Direct File Open
You can open `index.html` directly in any browser:
```powershell
Start-Process "C:\Users\sgarm\stephanie-perez-portfolio\index.html"
```
